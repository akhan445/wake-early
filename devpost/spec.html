Wake Early: how it’s built

React + Vite in the browser, phone-sized. No server, no database. Everything lives in the browser.

The pieces and how data moves

Build order (kernel first, stop when time runs out)

  1. Coffee: search ~15 drinks, mug, pour, draining level, moving red line, curve to bedtime
  2. Alarm → Maze → Home: “Ring alarm now,” solve the maze, rings sparkle
  3. Home: nested rings, path bar, ladder, week columns (sample week)
  4. Sleep: bars with a dashed 11 pm–6 am window

The caffeine math

In your system now = each drink’s mg × ½ for every 5 hours since you drank it.

Red line now = 50 mg × 2 for every 5 hours until bedtime. That’s the most you can have now and still be down to ~50 mg by 11 pm.

5 h half-life and 50 mg are approximate general values, not medical advice. Lives in lib/caffeine.js.

Run it & record it

cd app && npm install && npm run dev → open http://localhost:5173 in a phone-sized window → record Coffee → Ring alarm → maze → Home sparkle → Sleep.

Simplified for the deadline

React instead of Flutter: no install time; same design for a later Flutter rebuild.
~15 hand-picked drinks instead of a drink API.
“Ring alarm now” button: browsers can’t reliably wake a phone.
Fixed 11 pm / 6 am, no onboarding, one mug, gradients instead of animated scenes, no phased schedule or check-in.
